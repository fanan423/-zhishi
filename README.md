# 知时 · 安农校园信息雷达

> **学生错失机会，不是因为查不到，而是因为根本不知道有这回事。**

「知时」把散落在教务处、学院、学工、图书馆等公开通知页的信息，聚合成「**谁能报 · 剩几天 · 怎么办**」的提醒卡片，主动送到学生面前。核心跃迁：从「你问它答」的检索，变成「不问也给」的预警——**判断发生在 AI 这边，不是用户这边**。

原创代码类参赛作品 · 安徽农业大学 · 截止 2026-12-03 23:00。

| 大模型理解层 | 构建期真调 **36/36**，提示词 v1.1.0，46 条结构化产物回流 |
| AI 推荐层 | 构建期真调 **22/22**，提示词 v1.0.0，注入实用版；联网可切实时 |
| 自检 | `run_all.js` **27/27** · 交叉校验 **73/73** · 接口自检 **91/91** |

**架构边界（答辩务必说清）**：理解层与推荐层都真调了大模型，但都是**构建期离线调用**——模型把通知读懂、把推荐算好，结果写进交付产物；端上只读结果、不实时请求，因此**断网可完整演示**。规则加权算法保留为降级基线与可解释对照，**不把规则结果冒充 AI**。

## 快速开始（无需安装依赖）

直接双击项目根目录的：

- **`知时门户.html`** — 统一入口，左侧导航打开所有演示形态（推荐从这里看起）
- **`知时_可用版.html`** — 主应用单文件版，含主动送达清单与「✨ AI 推荐」区块
- **`知时_演示版.html`** — 10 屏静态演示版（纯离线保险，刻意不接入 AI 区块）

或使用 Windows 一键脚本：`一键运行.bat`。

小程序：`miniprogram/` 目录用微信开发者工具「导入项目」即可；`小程序预览.html` 可在浏览器看十页预览。

## 四层链路

```
采集（确定性 HTTP，注册表驱动）→ 理解（构建期大模型抽取五要素 + 引文锚点）
→ 匹配（AI 推荐重排 + 规则保底）→ 提醒（三问式卡片 + 双向溯源）
```

紫色两层（理解、匹配）才真调大模型，且都在构建期。详见 [`docs/答辩速讲稿.md`](docs/答辩速讲稿.md) 的架构图与 [`docs/参赛作品说明.md`](docs/参赛作品说明.md)。

## 开发与自检

需要 Node.js 18+ 与 Python 3（部分校验需 `python-docx`）。

```bash
npm install                 # jsdom + 云端 SDK（SDK 来自 npmmirror）
npm run checks              # 一键全量自检（27 个守卫）
npm run agent               # 智能体运行器（规则版，本地不调模型）
npm run agent:llm            # 真调大模型理解（需 config/cloud.local.json 凭证）
```

常用构建：

```bash
node tools/build_app.js            # 由 app_shell.html + 数据源重建 知时.html
node tools/build_usable.js         # 生成 知时_可用版.html（注入 AI 快照）
node tools/build_presentation.js   # 生成 知时_演示版.html
node tools/build_portal.js         # 生成 知时门户.html
node tools/build_two_versions.js   # 重打 dist/ 两版交付 zip
node tools/agent/build_ai_snapshot.js  # 构建期真调模型产出 AI 推荐快照
```

## 目录结构

| 路径 | 说明 |
|---|---|
| `知时*.html` / `知时门户.html` | 各形态单文件应用与统一门户（唯一真源产物） |
| `miniprogram/` | 微信小程序源码（十页 + utils） |
| `web/` | 数据层与逻辑层（`zhishi-data.js` / `zhishi-core.js` / `zhishi-agent.js` / `zhishi-ai.js`） |
| `tools/` | 采集、理解、导出、打包工具集，见 [`tools/README.md`](tools/README.md) |

| `tools/agent/` | 智能体服务端（`/api/recommend` 等）、提示词、推荐引擎 |
| `config/cloud.example.json` | 云端配置模板（真实凭证 `cloud.local.json` **不入库**） |
| `data/` | 真实采集结果 `notices_real.json` 与源健康度 |
| `docs/` | 参赛说明、答辩讲稿、AI 举证、提交行动卡 |
| `dist/` | 两版交付 zip（本地构建产物，不入库） |

## 合规边界

只采集**无需登录的公开通知页**；教务后台等私域数据明确不做。每条通知保留可核对的官网原文链接，演示样例一律标注来源、不假装有原文。详见 [`docs/参赛作品说明.md`](docs/参赛作品说明.md) 与 `docs/数据血缘与单一事实来源.md`。
