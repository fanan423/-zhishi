# 知时 · 安农校园信息雷达

> **校园公开信息的智能聚合与个性化提醒智能体**
> 「农芯智」AI 智能体创新大赛 · 参赛作品说明（草稿 v1）

---

## 一、项目定位（一句话）

> **学生错失机会，从来不是因为"查不到"，而是因为根本不知道有这回事。**
> 本项目把分散在教务处、学院、学工、图书馆的公开通知，聚合成一张张"谁能报 · 剩几天 · 怎么办"的提醒卡片，主动送到学生面前——做一个**会主动找你的校园信息雷达**。

---

## 二、真实痛点：不是懒，是信息架构问题

| 常见误解 | 真实情况 |
|---|---|
| "学生不看教务系统是懒" | 通知分散在**教务处 / 学院 / 学工 / 图书馆 / 公众号 / 班群**六个地方，学生不知道**去哪儿找**、也不知道**有这回事** |
| "问一下就知道了" | 学生不知道**该问什么**。机会错过不是因为问不到，是因为**不知道要问** |
| "学校已经做了问答助手" | 现有助手只解决**"你问它答"（检索）**，不解决**"不问也能收到"（预警/推送）** |

**核心矛盾：** 信息存在，但到达不了该看到它的人手上。
**本项目切口：** 从"检索"跃迁到"**预警/推送**"——判断发生在 AI 这边，不是发生在用户这边。

---

## 三、合规说明（关键，务必保留）

本项目的合规边界是设计的前提，不是补丁：

1. **数据源仅为公网公开页面** —— 教务处官网通知页、各学院官网、学生工作处、图书馆、创新创业学院等**任何人无需登录即可访问**的公开页面。
   - 等同于"人工去各大官网翻通知"的自动化，**合规、正当**。
2. **不涉及教务系统后台** —— **不登录、不代登录、不抓取任何需鉴权的内部系统**。项目所有对外表述统一使用"**聚合 / 归集 / 智能解析**"，**不使用"爬取教务系统"类表述**。
3. **不获取私域与敏感数据** —— 课表、成绩、一卡通等个人数据**不采集**。若需个性化，仅做"**用户本地授权导入**"（用户自行粘贴/截图/本地解析），**数据不出用户本地**。
4. **对用户的价值来源合法** —— 个性化来自"**公开信息 × 用户主动填写的关注偏好**"，而非任何隐私数据挖掘。

> 一句话：**我们抓的都是别人看得见的东西，我们只是把它整理好、送到该看的人手上。**

## 四、系统架构（四层链路）

```
┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐
│  采集层  │ → │  理解层  │ → │  匹配层  │ → │  提醒层  │
│ 公开页抓取│   │ AI 抽取  │   │ 画像×事件│   │ 倒计时卡片│
└─────────┘   └─────────┘   └─────────┘   └─────────┘
```

| 层 | 职责 | 关键设计 |
|---|---|---|
| **采集层** | 定时抓取公开通知页、校历、公开培养方案 | 静态页 + 少量动态页；演示覆盖 3–5 个真实页面 |
| **理解层** ⭐ | LLM 抽取 **事件类型 / 适用人群 / 截止时间 / 所需材料 / 办理入口** 五要素 | **本项目核心亮点**；输出置信度，低置信度标"待人工核对" |
| **匹配层** | 用户画像（年级/学院/关注类别）× 事件属性 | 仅匹配公开信息，不碰私域数据 |
| **提醒层** | 倒计时预警卡片 + 分类订阅 | "谁能报·剩几天·怎么办"三问式呈现 |

**理解层示例（一条通知 → 结构化字段）：**

| 字段 | 抽取结果 |
|---|---|
| 事件类型 | 转专业 |
| 适用人群 | 2025级全日制本科（无处分、绩点≥2.5） |
| 截止时间 | 2026-11-18（窗口 11/10–11/18） |
| 办理入口 | 教务系统 → 转专业申请模块 |
| 关键提醒 | 窗口仅9天 / 限报一个专业 / 考核在11/25–11/28 |
| 置信度 | 96%（可直接推送） |

## 五、技术实现清单（对应评分表）

| 评分项 | 权重 | 本项目对应 |
|---|---|---|
| **创新性** | 30% | 从"问答检索"到"**主动预警**"的范式跃迁；"**AI 懂通知**"而非"抓通知" |
| **实用性** | 25% | 真实痛点 + 公开源即可落地 + 每个学生都用得上 |
| **技术实现** | 25% | 完整工作流编排 + 向量知识库 + 结构化字段抽取 + 定时/推送插件 |
| **用户体验** | 20% | 分类订阅、"三问式"卡片、倒计时预警、置信度提示 |

**技术栈（建议）：**
- 采集：`requests` + `BeautifulSoup`（或 `Playwright` 处理动态页）
- 理解：LLM 结构化抽取（few-shot + JSON schema 约束输出）
- 存储：向量库（通知语义检索）+ 结构化事件表
- 提醒：定时任务 + 卡片渲染（Web / 微信小程序均可）
- 展示：本项目 Demo 为**纯前端单文件**，无需后端即可演示
