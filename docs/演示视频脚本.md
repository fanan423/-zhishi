# 演示视频逐镜脚本 · 知时 · 安农校园信息雷达

> **用途**：录屏时**照念即可**。每一镜给出「时间轴 / 屏幕动作 / 口播词 / 素材位置」。
> **总时长设计：4 分 45 秒**（上限 5 分钟，留 15 秒余量，防手抖超时）。
> **导出要求**：**MP4**、**≤5 分钟**、建议 1080p / 30fps，文件名
> `<学号>+<个人标识>+知时·安农校园信息雷达+演示视频.mp4`。
> **录制工具**：Windows 用 **Win+Alt+R**（Xbox Game Bar）或 OBS；录完用剪映/格式工厂转 MP4。

---

## 〇、录制前 5 分钟准备清单

| # | 动作 | 怎么确认做对了 |
|---|---|---|
| 1 | **断网**（拔网线 / 关 WiFi） | 说明"离线可演"才可信；本项目双击即开，不联网完全够用 |
| 2 | 双击 `知时门户.html`，确认能打开 | 左导航能看到 13 个入口 |
| 3 | 关掉所有通知弹窗、微信、QQ | 避免录进隐私信息 |
| 4 | 壁纸换成纯色、桌面图标清空 | 画面干净，评审观感好 |
| 5 | 屏幕缩放设 **125%**（如果字太小） | 录出来文字清晰可读 |
| 6 | 用**记事本把本脚本打开放在副屏/手机**上 | 口播词照念，不用背 |
| 7 | **先试录 30 秒**听一遍声音 | 确认麦克风无明显底噪、无爆音 |

> 💡 **一条重要提醒**：录屏前**先跑一次 `一键运行.bat`**（或直接双击门户），
> 确保 demo 数据是新鲜的、倒计时是活的。本项目内置倒计时实时刷新，
> 打开就是对的，但跑一次更稳妥。

## 三、录制技术要点

| 项 | 建议 |
|---|---|
| **分辨率** | 1920×1080（1080p）。若屏幕是 2K/4K，缩放到 1080p 再录，避免字太小 |
| **帧率** | 30fps 足够；60fps 文件更大、无必要 |
| **音频** | 用耳机麦克风或手机贴近录，避免房间回声；**先试录 30 秒回听** |
| **鼠标** | 录屏时**放大鼠标指针**（Windows 设置 → 辅助功能 → 鼠标指针大小），动作放慢 |
| **剪辑** | 用剪映/必剪：**掐头去尾**（开头留 1 秒静止）；**加字幕**（脚本里的"字幕提示"就是字幕文案）；**加背景音乐**（音量压到 -20dB 左右，别盖过口播） |
| **时长校验** | 导出后**务必看总时长**：必须 **≤ 5:00**。本脚本设计为 4:45，若实际超了，优先压缩第 8、9 镜（技术底座类可以讲快一点） |
| **格式** | 导出 **MP4（H.264）**；不要用需要特殊播放器的格式 |

## 五、答辩现场演示预演（配套准备）

视频是"评审依据"，但**答辩环节必须现场运行**。提前练这套 90 秒动线：

1. 双击 `知时门户.html`（断网）→ 20 秒
2. 点「可用应用」→ 看推送卡片 → 点进一条详情 → 演示溯源高亮 → 40 秒
3. 进「推送设置」→ 看触达时间线 + 点一次订阅授权 → 20 秒
4. 切「问知时」问一句 → 看「依据」→ 10 秒

> ✅ 这条动线**全部离线可用**，答辩现场零网络风险。
> 建议**提前 3 天练 3 遍**，掐表控制。
