## 三、抓取链路修复（本轮实质改进）

### 1. 相对链接解析错误（导致详情页 404）

安农二级站的详情链接有两种写法：

- **绝对路径**：`/info/1151/6161.htm`（信院、工学院、工会、保卫处、人事处）
- **相对路径**：`../info/1101/25926.htm`（经管）、`../../info/2401/55481.htm`（图书馆）

旧代码按站点根硬拼 `base + href`，会把 `../` 保留成字面路径，服务器直接 404：

```
✗ 旧：https://jgxy.ahau.edu.cn/../info/1101/25926.htm  → 404
✓ 新：https://jgxy.ahau.edu.cn/info/1101/25926.htm     → 200
```

**修复**：改用 `urljoin` 按「列表页自身地址」解析相对链接。
**效果**：抽查 25 条详情页从「部分 404」变为 **25/25 全部 200**；图书馆活动通知 5 条 → 20 条。

### 2. 正文模板噪声（污染信息真实性）

详情页会在正文前后混入同一套导航/元信息：

```
请输入您搜索的信息！ 首页 / 通知公告 / 正文 中暑假期值班安排表
作者：工学院 来源：工学院 点击数： 发布时间：2026-09-24 10:59:32
上一条：xxx 下一条：xxx 版权所有 © 安徽农业大学 皖ICP备...
```

**修复**：新增 `denoise_body()` 逐行/逐段清洗（噪声前缀 + 内联元信息正则 + 面包屑）。
**效果**：`请输入您搜索的信息` 4 → **0**；`网站首页` 24 → **0**；`上一条/下一条/作者/发布时间` 约 30 → **0**。

### 3. 来源单位映射错误（导致学院归属失效）

注入脚本按短码 `gxy` 查表，但数据实际是栏目全称「机械与车辆工程学院（工学院）· 通知公告」，
查表必然落空、退化成冗长全称 → **「各花入各眼」学院归属识别失效**。

**修复**：新增 `resolve_unit()`，长短两种写法都归一到规范来源名。
**效果**：`source` 字段从「机械与车辆工程学院（工学院）· 通知公告」规范为「机械与车辆工程学院（工学院）」。
