# 知时 · 两版交付说明

> 生成日期：2026-11-15 ｜ 适用：`知时_项目全量` 优化后交付
> 一句话：**「演示版」给评委看，「可用版」给师生用。两者同一份数据、同一套算法，都断网可演、双击即开。**

## 一、两个版本，怎么选

| | **演示版** `知时_演示版.html` | **可用版** `知时_可用版.html` |
|---|---|---|
| 给谁 | 评委 / 答辩投屏 / 录演示视频 | 真正要使用它的师生 |
| 形态 | 全屏分屏翻页，10 屏引导式叙事 | 完整手机应用（四 Tab + 八项能力） |
| 组织方式 | **按官方四维评分 + 五个技术评分点**逐项举证 | 按使用场景组织：雷达 / 时间轴 / 简报 / 我的 |
| 字号 | 主标题 ≥32px、KPI ≥48px，投屏可读 | 移动端常规字号 |
| 能点吗 | 可翻页、`#N` 直达第 N 屏（**1 起**，与右下角页码一致；`#6` AI 举证、`#7` 现场演示），第 7 屏可跳进可用版现场操作 | 全部功能真能点：订阅、搜索、溯源、问答、日历、推送 |
| 数据 | 与可用版**同源**，KPI 构建期现算 | 同一份 `web/zhishi-data.js` |
| 依赖 | 单文件，零依赖，断网可演 | 单文件，零依赖，断网可演 |

**推荐动线**：先打开演示版（评委/录视频）→ 第 7 屏点「打开可用版应用」→ 现场演示真实操作。
可用版顶部横幅也有「看演示版」回跳，两版互通。

> 两个 zip 均已产出：`dist/知时_演示版.zip`（轻量、单文件、断网可演）与
> `dist/知时_可用版.zip`（完整可运行程序，含小程序源码、网页数据、工具链、文档）。
> 均为通用命名；正式提交另用 `tools/pack_submission.py --sid <学号> --team <队名>` 按官方格式产出。

## 四、断网演示清单（答辩前照做）

1. 双击 `知时_演示版.html` → 用 ← / → 或空格翻页，`#6` 直达 AI 举证屏（屏号 1 起）。
2. 第 7 屏点「打开可用版应用」→ 新窗口打开 `知时_可用版.html`（同屏右侧为内嵌预览）。
3. 可用版里演示：改档案 → 雷达推送流重排 → 点卡片看浓缩 / 依据原文 / 大模型理解 → 简报 → 问知时。
4. 全程不联网：`file://` 直开，两个文件都是自包含单文件。
5. 若要录视频：演示版屏序已对齐 `docs/演示视频脚本.md` 的逐镜顺序（4'45"），照屏录即可。

## 五、重新生成（改了数据之后）

```powershell
$env:PYTHONIOENCODING = "utf-8"
$py = "C:\hclaw\python\python.exe"

& $py tools\export_mp_data_to_web.py     # ⑥ 网页数据源
node tools\build_app.js                  # 可用应用内核
node tools\build_usable.js               # 知时_可用版.html
node tools\build_presentation.js         # 知时_演示版.html
& $py tools\build_demo.py                # 交互 Demo
node tools\build_portal.js               # 统一门户
node tools\sync_promo_kpi.js             # 宣传物料 KPI 同步
node tools\build_two_versions.js         # 两版 zip（纯 Node，零依赖，中文路径安全）
node tools\checks\run_all.js             # 全量自检必须全绿
```

> 打包器用 `tools/lib/zip_writer.js` 纯 Node 写标准 ZIP，**不调用 PowerShell**，
> 因此含中文的工作区路径不会 mojibake；文件名以 UTF-8 + flag `0x0800` 写入，
> Windows 资源管理器 / 7-Zip / Python `zipfile` 解压均不乱码。

> 若重跑了采集（`collect_notices.py`），必须额外先跑
> `node tools/agent/reset_llm_baseline.js` 重建 LLM 回流基线，
> 以及 `RESAMPLE_AUDIENCE=1` 重抽受众。详见 `docs/数据血缘与单一事实来源.md` 第五节。
