知时 · 安农校园信息雷达

校园公开信息的智能聚合与个性化提醒智能体
学生错失机会，从来不是因为"查不到"，而是因为根本不知道有这回事。

知时把分散在教务处、学院、学工、图书馆的公开通知，聚合成一张张 "谁能报 · 剩几天 · 怎么办" 的提醒卡片，主动送到学生面前—— 做一个会主动找你的校园信息雷达。
亮点 01
理解后重构

800 字通知压成 3 句人话。不是搬运原文，是读懂再重写。

亮点 02
全链路溯源

每个结论都挂原文出处，点一下就能核对。可信的智能。

亮点 03
可解释的主动推送

只推与你身份、关注相符的通知，排序由可解释分数决定、可追溯；详情页可逐条核对「是否与我有关」；只有三天内截止才允许打扰。

亮点 04
问答 · 自问自答

13 个高频疑问一问一答，每个答案都由真实字段算出、附「依据」一行，算不出就如实说算不出。

亮点 05
日历

把有截止的通知落到月历格子上，一眼看清哪天忙、哪天能空。与日程同一份数据，不是两套事实。

怎么真的跑起来 三种形态，都已可运行
形态 A · 可用应用（推荐先看）

双击「知时.html」

项目根目录里的 知时.html：一个单文件、零依赖、双击即用的完整应用。 手机壳界面里四页可操作：通知（主动通知列表）· 日程 · 汇总（自动整合）· 我的（自主完善档案）。 每条通知都贴着出处：「可核对原文 / 真实采集 / 演示样例」。内置主动推送引擎 （可解释评分排序 + 只推相符通知 + 详情页可逐条核对 + 只有三天内才打扰）、数据自查 （三条铁律，不可靠的剔除、可疑的如实标注）、问答（13 问自问自答，答案带依据）与 日历（月历看清哪天忙）。

形态 C · 后台主动推送

双击「tools/注册后台推送.bat」

应用内推送只在你打开时工作。注册后台任务后，关掉页面也能收到提醒： 每天 08:00 / 20:00 自动检查安农公开通知，有三天内截止的就弹系统原生通知， 并落一份 push_out/今日推送.txt，写明「推了什么、为什么推、来源是哪」。 零依赖（用 Windows 自带的 PowerShell 弹通知），弹出失败则降级写文件，绝不静默失败。

时间动作话术要点
0:00–0:30开场故事用本人真实经历：大一错过一条通知，发现问题不是懒，是通知散在六个地方，根本不知道有这回事
0:30–1:45点「运行智能体」四阶段依次点亮 → 讲链路：采集公开页 → AI 理解 → 画像匹配 → 主动推送
1:45–2:00点开一张卡片「判断发生在 AI 这边，不是用户这边」——本作品最重要的一句话
2:00–3:00浓缩 + 溯源页点要点 → 展开出处 → 跳原文 → 高亮定位 → 全部高亮。「不是读给你听，是读完告诉你重点，而且你能查证」
3:00–3:30改订阅再重跑勾掉一项 → 回首页重跑 → 卡片数变少。「匹配是活的，用户完全可控」
3:30–4:00切到边界面板指着教务系统那行：「这条我们明确不做。技术能绕，但合规不能碰」
4:00–5:00讲差异化 + 收尾三个亮点；收尾用大赛通知原文——获奖作品将上线数智安农，「我们不是要绕过学校平台，我们想成为它的一部分」

合规边界（设计前提，不是补丁）

只用：教务处、学院、学生工作处、图书馆等公网公开通知页面； 用户在小程序内主动填写的年级、学院、关注偏好。

不碰：教务系统后台、任何需登录鉴权的内部系统； 课表、成绩、学籍、一卡通等私域与敏感数据。

一句话：我们聚合的都是别人看得见的东西，我们只是把它整理好、送到该看的人手上。
