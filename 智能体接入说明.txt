知时 · 智能体服务接入说明
========================================

一、这个提示是什么
小程序「我的 / 今日清单」里显示"本地模式（未部署智能体服务）"，
不是报错，是工程默认没配服务端地址。功能完整，只是清单由小程序自己算，
不含服务端常驻 + 大模型理解层。

服务端源码本来就在工程里：tools/agent/server.js（零外部依赖，只用 Node 内置模块）。
所以"部署"= 把它跑起来 + 让小程序连上，不需要新写代码。

二、三步接入
1) 把「启动智能体服务.bat」放到工程根目录（有 tools\ 文件夹的那一层），双击。
   出现"知时·智能体服务已启动"，窗口保持开着别关。
   地址固定为 http://127.0.0.1:8787

2) 微信开发者工具 → 详情 → 本地设置 →
   勾选「不校验合法域名、web-view、TLS 版本以及 HTTPS 证书」
   （不勾的话 http://127.0.0.1:8787 会被 wx.request 直接拦掉）

3) 让小程序带上地址，二选一：
   A. 把「覆盖用\app.js」覆盖到小程序工程根目录，重新编译（推荐，一次到位）；
   B. 不改代码：小程序「我的 → 智能体服务 → 改地址」填 http://127.0.0.1:8787
      点「保存并探测」（会存进 storage，之后不用再填）。

成功后「我的」页显示：已连接智能体服务 / 服务版本 1.0.0。
「今日清单」页显示"服务端算"，且不再出现降级黄条。

三、验证过的接口（2026-11-09 本机实测）
GET /healthz                → ok: true, status: alive
GET /readyz                 → cloud: ok, notices: ok(154 条), engine: ok
GET /api/version            → 知时·智能体服务 v1.0.0, Node v22.22.2
GET /api/digest?useLLM=false→ 通知池 156 条 / 入库 149 / 命中 12 / 主动提醒 1 / 静默 11

四、几个注意点
· bat 默认 AGENT_LLM_DEFAULT=0（规则模式），保证断网答辩机也能起。
  想开大模型理解层：改 bat 里为 =1，并在「我的」页点「立即跑一轮」时选 LLM。
· 真机预览：127.0.0.1 指向手机自己，连不上。
  把 bat 里 --host 127.0.0.1 改成 --host 0.0.0.0，
  再把 app.js 的 127.0.0.1 换成电脑的局域网 IP（ipconfig 查），手机与电脑同一 WiFi。
· 正式发布（体验版/正式版）：小程序强制 https + 服务器域名白名单，
  本机 http 地址不能用，需要公网部署并把域名加进微信公众平台。
· 服务没开时小程序会自动降级回本地算法，不会白屏，只是会显示"服务未连接"。
